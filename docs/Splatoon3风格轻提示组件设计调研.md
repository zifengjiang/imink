# 《斯普拉遁3》风格轻提示（Toast）设计调研

面向 iOS / SwiftUI 端轻提示组件的选型调研，覆盖成功、失败、进行中、导入导出进度四类场景，不含代码。

## 一、原作里适合承载「短提示」的元素

- **墨水喷溅**：结算与转场都用墨块遮挡擦除，天然适合覆盖一小块的瞬时反馈。
- **粗体压缩斜字 + 深色描边**：HUD 靠字号、倾斜和描边建立冲击力，适合「一句话喊出来」。
- **贴纸 / 胶带 / 撕边纸片**：Splatfest 海报的常用手法，观感随意且可读性最好。
- **斜切平行四边形面板**：HUD 与装备卡的通用骨架，比圆角矩形更不像系统控件。
- **黄黑警示斜纹**：通用的危险语义，适合警告，但只该局部使用。
- **橡皮章**：胜败结算的盖章字，适合终态那一下的情绪落点。
- **Judd's Advice**：原作里裁判猫给玩法提示的卡片，本身就是短提示的原型，气质最准但需要美术头像。
- **网点半调 / 墨色双色**：只做质感，不宜当文字背景大面积铺。

## 二、三个可选方向

**A. 贴纸卡（主干）**
视觉：撕边纸片或斜贴方卡，左上一条胶带，整体旋转 -2°；文字用系统粗体，墨色描边 + 极淡网点底纹，角标小图标。
动效：像被「贴上去」——从 1.12 倍缩回、一次轻回弹与旋转归位；消失时向右上抬起淡出。
适合：成功、普通信息、带副标题的文案、复制保存这类高频轻反馈。复杂度：低，纯 SwiftUI 形状即可。

**B. 墨点印章（仅用于成功/失败终态）**
视觉：预置的不规则墨斑作底，文字压在中心，字重与倾斜最大，外圈细飞溅点。
动效：盖章式冲击，1.4 倍压到 1，配一次轻微屏幕位移与触感；退场墨斑向内收干。
适合：1 秒内判定的情绪反馈，不适合长文案。复杂度：中，需自定义绘制墨斑轮廓。

**C. 斜切 HUD 进度条（进行中/警告）**
视觉：顶部一条薄斜切条，左图标、中间粗斜体文字、右百分比；进度用「墨量液面」从左灌满，警告态换成流动的黄黑斜纹。
动效：斜向切入，完成时被终态盖章覆盖后一并退场。
适合：导入导出、批量任务、后台同步与警告。复杂度：低到中，斜切靠自定义裁剪形状。

## 三、取舍

**可读性**：墨斑与网点只能做边缘质感，文字区要留干净深色底；正文不小于 15pt，中文用系统粗体即可有分量，不要为了「像」套窄体倾斜字体。失败不能只靠颜色区分。

**克制**：一次只常驻一条；成功 1.2~1.5 秒、失败 3 秒、进度常驻至终态；冲击动效只占入场前 0.3 秒。

**堆叠**：放弃系统式自上而下的瀑布列表，改为「同槽位替换 + 队列」；同类提示合并成一句（如「已导入 3 个」），失败可抢占槽位，进度在槽位里原地变成成功/失败终态。

**无障碍**：开启「减弱动态效果」时去掉缩放冲击、飞溅与位移，降级为原地淡入淡出，位置与停留时长不变；高对比大字，必要时用系统播报朗读；触感提供关闭项。

## 五、推荐

以 **A 贴纸卡作为唯一样式主干**承载全部短提示，用 **B 的盖章动效**只强化成功/失败那一瞬的入场与终态，用 **C 的斜切条**专门承接导入导出与后台任务这类长驻状态。

理由：贴纸卡信息容量够、文字最清晰、观感彻底脱离系统横幅的圆角玻璃气质，且改动成本最低——现有提示体系的「单条槽位 + 定时消失 + 进行中转终态」语义可原样保留，只换外观与动效。盖章只出现在 0.3 秒的入场峰值，游戏感够但不吵；进度独立成形态，避免长任务被塞进会超时消失的提示里。
